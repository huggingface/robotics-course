# Начало работы с LeRobot

На протяжении этого курса мы будем использовать LeRobot, всеобъемлющую библиотеку робототехники с открытым исходным кодом от Hugging Face, которая демократизирует доступ к передовым техникам обучения роботов. LeRobot решает одну из самых больших проблем в образовании и исследованиях робототехники: сложность работы с реальными роботизированными системами и данными.

Библиотека предоставляет интуитивную обработку наборов данных, которая делает работу со сложными данными робототехники такой же простой, как работа с текстом или изображениями в традиционном машинном обучении. У вас будет доступ к предобученным моделям, которые служат сильными отправными точками для ваших собственных проектов, позволяя вам строить на проверенных алгоритмах, а не начинать с нуля. LeRobot также поддерживает развертывание на реальном роботизированном оборудовании, соединяя разрыв между симуляцией и реальными приложениями. Возможно, самое главное, он связывает вас с растущим сообществом практиков обучения роботов, от исследователей в ведущих учреждениях до любителей, создающих удивительные проекты дома.

> [!TIP]
> **Предварительный просмотр установки:** Мы пройдем через установку LeRobot в разделе 2, но если вы хотите начать:
>
> ```bash
> pip install lerobot
> ```
>
> Ознакомьтесь с [репозиторием LeRobot на GitHub](https://github.com/huggingface/lerobot) для получения дополнительной информации!
